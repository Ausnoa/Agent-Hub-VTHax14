## Brand & Style

The design system establishes a high-performance, cinematic visual architecture for next-generation artificial intelligence orchestration. Geared toward machine learning engineers, systems architects, and technical founders, the atmosphere bridges deep-space computation with precision optical physical materials. 

The aesthetic is anchored in **Liquid Glassmorphism & Specular Minimalism**:
- **Atmosphere:** Pitch-dark, obsidian voids punctuated by ultra-refined refractive surfaces, razor-sharp specular rims, and delicate spectral dispersions.
- **Tone:** Authoritative, ethereal, surgical, and serene. It eliminates consumer noise in favor of luminous data density, calm telemetry, and high-fidelity spatial depth.
- **Physicality:** Surfaces mimic multi-layered, low-iron optical glass hovering over a crystalline dark matrix. Optical light corridors, luminous bezier paths, and focused atmospheric blooms guide cognitive focus through complex multi-agent execution graphs without sensory fatigue.

## Colors

The palette operates in strict tonal layers over deep abyss-grade foundations, accented by spectral chromatic wavelengths indicating execution state, telemetry flow, and verified compute integrity.

- **Canvas & Abyssal Foundation:**
  - Base Void: `#08080A` (dominant background canvas)
  - Secondary Void: `#0D0D12` (recessed canvases, graph orchestrator surfaces)
  - Surface Float: `rgba(255, 255, 255, 0.03)` to `rgba(255, 255, 255, 0.07)` with multi-tier optical blur.

- **Specular Accents & Micro-Strokes:**
  - Refractive Edge: `rgba(255, 255, 255, 0.12)` providing razor-thin perimeter boundaries.
  - Highlight Crest: `linear-gradient(135deg, rgba(255, 255, 255, 0.25) 0%, rgba(255, 255, 255, 0.03) 60%, rgba(255, 255, 255, 0.0) 100%)` for directional top-lit sheen.

- **Spectral Telemetry Accents:**
  - **Spectral Cyan (`#00F0FF`):** Real-time data streams, active graph nodes, low-latency telemetry conduit strokes.
  - **Spectral Violet (`#8B5CF6`):** Agent-to-agent cognitive handshakes, generative transformation states, neural pipeline branches.
  - **Spectral Emerald (`#10B981`):** ANS verification tokens, cryptographic health checks, validated cluster executions.
  - **Spectral Amber (`#F59E0B`):** Rate throttles, context-window degradation, telemetry warnings.
  - **Spectral Rose (`#F43F5E`):** Node aborts, memory boundary violations, circuit halts.

- **Text Contrast Hierarchy:**
  - Pure High-Contrast White: `#FFFFFF` (headings, active parameters)
  - Refined Specular Gray: `#94A3B8` (secondary metadata, telemetry labels)
  - Deep Muted Carbon: `#475569` (disabled parameters, wireframe scaffolding)

## Typography

The typographic hierarchy combines three specialized voices to establish high-precision structural tension:

1. **The Heroic Editorial Voice (`Playfair Display`):** Used selectively for landing titles, hero narrative anchors, and orchestrator milestone callouts. Set with slight negative tracking to imbue high-craft intellectual elegance.
2. **The Structural Computational Body (`Plus Jakarta Sans`):** Clean, geometric, neutral, and razor-sharp on OLED screens. Powers all interface layouts, property inspectors, navigation panels, and interactive controls.
3. **The Telemetry & Instrument Voice (`JetBrains Mono`):** Dedicated to ANS registry addresses, latency markers, token budgets, floating-point weights, and JSON schema configurations.

Use uppercase styling strictly for `label-caps` and `label-telemetry` to evoke precision aerospace instrumentation.

## Layout & Spacing

The layout model balances an open-canvas infinite graph plane with rigid, modular glass dock panels:

- **Desktop (>= 1280px):** 12-column variable grid for dashboard views, dynamic infinite viewport with fluid dockings for the orchestrator canvas. Split-screen panels maintain minimum widths of 380px with fixed `margin` (2rem) and `gutter` (1.5rem).
- **Tablet (768px - 1279px):** 8-column layout. Node parameters and telemetry inspectors collapse into collapsible glass slide-overs.
- **Mobile (< 768px):** Single-column stacked stream. The node-composer canvas flips into a sequential pipeline card stack with swipe transitions. Section margins compact to `margin-sm` (1rem).

Internal component density follows a strict 4px base rhythm (`space-xs` through `space-xl`) to maximize screen real estate for deep workflow configuration.

## Elevation & Depth

Visual depth is achieved through optical light refraction and multi-layered specular materials rather than traditional heavy drop-shadows.

1. **Layer 0 (Canvas Horizon):** Solid void `#08080A` with subtle SVG micro-dot grid (opacity 0.08) and localized ambient cyan/violet radial glows (blur 120px to 240px, opacity 0.12).
2. **Layer 1 (Recessed Well):** Inset surfaces (`#0D0D12`) with `box-shadow: inset 0 1px 2px rgba(0, 0, 0, 0.8)`. Used for terminal feeds, orchestrator canvas viewports, and payload previews.
3. **Layer 2 (Refractive Glass Tiles):**
   - Fill: `backdrop-filter: blur(24px) saturate(160%); background: rgba(255, 255, 255, 0.035);`
   - Border: 1px solid `rgba(255, 255, 255, 0.10)`.
   - Shadow: `0 8px 32px -4px rgba(0, 0, 0, 0.6)`.
4. **Layer 3 (Active Focus & Flyout Panels):**
   - Fill: `backdrop-filter: blur(40px) saturate(180%); background: rgba(255, 255, 255, 0.06);`
   - Border: 1px solid `rgba(255, 255, 255, 0.18)`.
   - Specular Rim: Pseudo-element linear gradient highlighting the top-left edge.
   - Glow: Subtle aura tinted with the active state color (e.g., `#00F0FF` at 15% opacity, blur 32px).
5. **Layer 4 (Luminous Bezier Conduits & HUD Overlays):**
   - Telemetry cables use SVG paths rendered with `filter: drop-shadow(0 0 6px rgba(0, 240, 255, 0.6))`.

## Shapes

The design system employs a refined modern curvature hierarchy:
- Base elements (buttons, inputs, telemetry chips): `0.5rem` (8px).
- Graph cards, agent containers, modals: `1rem` (16px).
- Primary orchestrator canvas viewports: `1.5rem` (24px).
- Circular tags, status indicators, and anchor ports: Pure rounded pill format (`9999px`).

Precision 1px hair-thin lines define all perimeter contours, simulating diamond-cut glass edging.

## Components

### Buttons
- **Primary Specular Button:** Dynamic refractive fill (`linear-gradient(180deg, rgba(255, 255, 255, 0.12) 0%, rgba(255, 255, 255, 0.04) 100%)`), border 1px solid `rgba(255, 255, 255, 0.22)`, top-edge specular highlight. Text pure white, medium weight. Hover triggers subtle inner glow (`box-shadow: inset 0 0 12px rgba(0, 240, 255, 0.2)`).
- **Secondary Glass Button:** Translucent background (`rgba(255, 255, 255, 0.03)`), border 1px solid `rgba(255, 255, 255, 0.08)`, text `#94A3B8`. Hover elevates to 10% white background with pure white text.
- **Ghost Action:** Borderless, zero fill. Telemetry text tinting to cyan or violet on hover.

### Chips & Orchestrator Badges
- **ANS Verification Chip:** Pill shape (`9999px`), height 22px, `rgba(16, 185, 129, 0.08)` background, border 1px solid `rgba(16, 185, 129, 0.3)`. Features a 6px pulsating emerald LED dot and `label-telemetry` text.
- **Telemetry Metric Badge:** Monospace pill displaying latency or token cost (`JetBrains Mono`, 10px), dark glass backdrop with sharp 1px border (`rgba(255, 255, 255, 0.08)`).

### Input Fields & Parameter Sliders
- Background `rgba(0, 0, 0, 0.45)`, border 1px solid `rgba(255, 255, 255, 0.10)`, text `#FFFFFF`. Focus transitions border to `rgba(0, 240, 255, 0.6)` with a 12px outer atmospheric bloom.
- In-line numeric steppers use monospaced fonts with miniature glass arrow triggers.

### Cards & Node Containers
- High-grade multi-layer glass composition: 1px continuous hairline outline, inner `inset 0 1px 0 rgba(255, 255, 255, 0.15)` for the glass rim refraction.
- Node header includes agent icon, instance identifier in `label-telemetry`, and floating drag anchor.

### Conduit Connectors & Ports
- Circular connection ports (10px) with 2px metallic borders. Inactive ports display `#475569`; connected/active ports emit a radiant glow (`#00F0FF` or `#8B5CF6`) connecting to animated stroke-dasharray SVG bezier conduits.

### Checkboxes & Toggle Switches
- Toggles utilize a sleek 18px-high glass chamber with a floating specular bead (`#FFFFFF`) that glows cyan upon engagement.
